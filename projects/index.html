SmallRye

Projects

The SmallRye projects: implementations of the Eclipse MicroProfile specifications, and standalone libraries such as Jandex and Mutiny.

Eclipse MicroProfile Platform

  • SmallRye Config

    A Java configuration library. Implements MicroProfile Config.

    Documentation of SmallRye Config → GitHub repository of SmallRye Config

  • SmallRye JWT

    Token verification and an API to build and sign tokens. Implements MicroProfile JWT RBAC.

    Documentation of SmallRye JWT → GitHub repository of SmallRye JWT

  • SmallRye Health

    Health checks for liveness, readiness and startup. Implements MicroProfile Health.

    Documentation of SmallRye Health → GitHub repository of SmallRye Health

  • SmallRye Fault Tolerance

    Bulkheads, circuit breakers, fallbacks, rate limits, retries and timeouts. Implements MicroProfile Fault Tolerance.

    Documentation of SmallRye Fault Tolerance → GitHub repository of SmallRye Fault Tolerance

  • SmallRye Metrics

    Application and runtime metrics. Implements MicroProfile Metrics.

    Archived

    Documentation of SmallRye Metrics → GitHub repository of SmallRye Metrics

  • SmallRye OpenAPI

    OpenAPI documents generated from your application's code. Implements MicroProfile OpenAPI.

    GitHub repository of SmallRye OpenAPI

  • SmallRye OpenTracing

    Distributed tracing with OpenTracing. Implements MicroProfile OpenTracing.

    Archived

    GitHub repository of SmallRye OpenTracing

  • RESTEasy REST Client

    Type-safe REST clients, part of RESTEasy. Implements MicroProfile REST Client.

    GitHub repository of RESTEasy REST Client

Eclipse MicroProfile Standalone

  • SmallRye Context Propagation

    Carries context, such as the current transaction or request, across threads. Implements MicroProfile Context Propagation.

    GitHub repository of SmallRye Context Propagation

  • SmallRye Mutiny

    An intuitive, event-driven reactive programming library for Java. Implements MicroProfile Reactive Streams Operators.

    Documentation of SmallRye Mutiny → GitHub repository of SmallRye Mutiny

  • SmallRye Reactive Messaging

    Event-driven, message-based applications on Kafka, AMQP, MQTT, RabbitMQ, Pulsar and more. Implements MicroProfile Reactive Messaging.

    Documentation of SmallRye Reactive Messaging → GitHub repository of SmallRye Reactive Messaging

  • SmallRye GraphQL

    GraphQL services, with type-safe and dynamic Java clients. Implements MicroProfile GraphQL.

    Documentation of SmallRye GraphQL → GitHub repository of SmallRye GraphQL

SmallRye Standalone

  • Jandex

    A space-efficient Java class file indexer and offline reflection library.

    Documentation of Jandex → GitHub repository of Jandex

  • SmallRye Stork

    Service discovery and client-side load balancing.

    Documentation of SmallRye Stork → GitHub repository of SmallRye Stork

  • Mutiny Vert.x bindings

    Mutiny APIs for Eclipse Vert.x.

    Documentation of Mutiny Vert.x bindings → GitHub repository of Mutiny Vert.x bindings

  • Mutiny Zero

    A zero-dependency Reactive Streams publishers library.

    Documentation of Mutiny Zero → GitHub repository of Mutiny Zero

  • SmallRye Common

    Common utilities for SmallRye projects and more.

    GitHub repository of SmallRye Common

  • SmallRye OpenTelemetry

    OpenTelemetry tracing for CDI and Jakarta REST. Implements OpenTelemetry.

    GitHub repository of SmallRye OpenTelemetry

  • SmallRye AsyncAPI

    AsyncAPI documents for MicroProfile applications. Implements AsyncAPI.

    Archived

    GitHub repository of SmallRye AsyncAPI

  • SmallRye Converters

    An API to convert a String to other types.

    GitHub repository of SmallRye Converters
